1. Upload limit

The frontend and backend accept 20 MB files, but uploads are sent as base64 JSON. A 20 MB file becomes larger than 20 MB in the request body.

Fix this by:
- increasing the Express JSON/urlencoded request body limit to at least 32mb
- keeping the actual MAX_BYTES file limit at 20 MB
- adding or preserving a clear error message when the request body is too large

Preferred first-build fix:
- app.use(express.json({ limit: "32mb" }))
- app.use(express.urlencoded({ extended: true, limit: "32mb" }))
- keep MAX_BYTES = 20 * 1024 * 1024

Option A, preferred for this first build:
- after successful server-side validation of file type, file size, file signature, and storage, store the document with validationStatus = "valid"
- keep extractedDataStatus = "pending" if real extraction is not implemented yet

Or option B:
- keep uploads as pending
- but update all gating/scoring logic so only validationStatus = "valid" counts for required documents

Whichever option you choose, make the UI status match the backend behavior.
